领克车机 ADB 工具 - 依赖说明
================================

1. Python 文件
   - 只需要 lynk_adb_tool.py 一个文件。
   - 代码只使用 Python 标准库：os / queue / re / subprocess / sys /
     threading / time / tkinter。
   - 不需要额外的 .py 模块，也不需要 pip 安装任何第三方包。
   - 自检：命令行运行 `python lynk_adb_tool.py --selftest`，
     会打印 adb / aapt2 的解析结果。

2. Python 运行时
   - Python 3.10 或更高版本。
   - 必须包含 tkinter（Windows 官方安装包默认包含；安装时勾选 tcl/tk）。
   - 启动器不再写死版本号，按顺序自动查找：
       1) 程序目录下的 python\（便携版，放进去即可用）
       2) uv 安装目录里的 cpython-*（%APPDATA%\uv\python、E:\Code\_tools\uv\python）
       3) 系统 PATH 里的 pythonw.exe
     找到后会先跑一次 `import tkinter` 验证，缺 tkinter 会明确提示而不是闪退。

3. 外部工具
   - adb.exe：必需。发布包内置在 tools\adb\；源码运行时按
     tools\adb → ANDROID_HOME\platform-tools → LOCALAPPDATA\Android\Sdk\platform-tools
     → D:/C:/E: 常见路径 → PATH 的顺序查找。
   - aapt2.exe：用来读 APK 资源（应用名、启动入口）。发布包内置在
     tools\aapt2\；源码运行时按 LYNK_AAPT2 环境变量 → tools\aapt2 →
     各 SDK 的 build-tools 最新版 查找。
     没有它仍能上传、安装、卸载，只是「② 启动应用」不可用、应用名显示为「—」。

4. 不需要的东西
   - 不需要 Node.js、Java、Gradle、Android Studio。
   - 源码运行时不需要把 adb 或 aapt2 复制进本目录（程序会自动查找）。

5. 排错
   - 双击「诊断启动.bat」：先用控制台打印自检结果，再启动程序，
     任何异常都会留在窗口里，不会一闪而过。
